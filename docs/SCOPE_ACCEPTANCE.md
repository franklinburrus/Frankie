# Product scope & first-thumbnail acceptance (repo mirror)

Thin mirror of [Frankie 02 — Product Scope and Thumbnail Acceptance](https://docs.google.com/document/d/1wxaHL60DZ478xveY1R6OY28aQpB-fwCfvnFkZC4AUpI). Drive remains authoritative.

## Phase 1 inputs

- Frank-authorized participant photographs
- Example/reference thumbnails
- Exact caption (or content-grounded proposed wording)
- Simple design directions (layout, color, tone, emphasis)

## Acceptance (Mac)

One authorized-media test produces:

- a decodable YouTube-compatible image
- accurate readable caption
- recognizable participants
- no invented events/quotes
- unchanged source hashes
- recorded software/model licence/provenance
- failed/uncertain cases surfaced; never auto-`READY`

Collage/overlay alone is **not** completed AI image generation. If no compatible local model exists, report it and propose the smallest install for Frank (D09) — do not install silently.

## Not Phase 1

Video animation, highlight extraction, timeline editor, cloud services, databases, publishing, training, voice cloning, complex orchestration.

## Definition of Done

Only real local execution on Frank’s Mac with one inspected source-to-output thumbnail validates Phase 1. Build success, UI mockups, or static-only composites alone are insufficient.
