# Start Here (repo mirror)

Thin mirror of [Frankie 01 — Start Here and Project Direction](https://docs.google.com/document/d/1ztNdAihe12uBRgGhswYlkY1iaQ6EhW_fOsEjMtESToU). Drive remains authoritative.

## First deliverable

Native SwiftUI Mac app that makes **one** real YouTube thumbnail locally from:

- authorized participant photographs
- Frank’s sample/reference thumbnails
- a caption
- simple style instructions

Prefer a suitable model/software already on the Mac. Put exact text on the image with deterministic composition when needed. Produce an inspectable export. This is **not** the animation engine.

## Build order

1. Verify repo + inventory local image models/tools/licences.
2. Smallest import → instruct → generate/edit → caption → preview → export path.
3. One authorized end-to-end test, then presets.
4. Only after thumbnails are useful: Phase 2 cartoon Shorts research.

## Boundaries

Local/offline after approved setup. No required cloud inference, paid APIs, telemetry, unauthorized uploads, or publishing. Preserve Caveman. Uncertain/failed checks are never `READY`. Evidence labels: `VERIFIED` / `REPORTED` / `PROPOSED` / `UNKNOWN`.
